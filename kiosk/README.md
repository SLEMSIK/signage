# Киоск Signage для Windows (OPS)

Плеер — это страница `http://<сервер>/player/`, открытая в Microsoft Edge в режиме киоска. Скрипты в этой папке настраивают плеер так, чтобы после включения питания он сам входил в Windows, открывал плеер на весь экран и перезапускал браузер, если тот закрылся или упал.

| Файл | Назначение |
|---|---|
| `install.ps1` | Установка: профиль Edge, задача планировщика, питание, уведомления, Windows Update |
| `watchdog.ps1` | Запускает Edge и перезапускает его каждые 10 с, если процесса нет |
| `uninstall.ps1` | Удаление и возврат всех изменённых настроек |
| `common.ps1` | Общие функции, подключается остальными скриптами |

## Требования

- Windows 10 или 11 (Pro, Enterprise, IoT/LTSC или Home).
- Microsoft Edge (уже есть в Windows). Если Edge нет, используется Google Chrome.
- Плеер видит сервер по сети (`http://10.33.44.20:8080/player/` открывается в браузере).

Редакцию скрипт определяет сам. На **Home** часть групповых политик (центр уведомлений, рекомендации Windows) не действует. Основное работает везде: автозапуск, перезапуск браузера, отключение сна. Всплывающие уведомления отключаются на уровне пользователя через `watchdog.ps1`.

## Установка

### 1. Создать локального пользователя киоска (без прав администратора)

PowerShell от имени администратора:

```powershell
$pass = Read-Host -AsSecureString 'Пароль для пользователя signage'
New-LocalUser -Name signage -Password $pass -FullName 'Signage' -PasswordNeverExpires -UserMayNotChangePassword
Add-LocalGroupMember -Group 'Users' -Member signage
```

Пользователь `signage` не входит в группу «Администраторы», поэтому из киоска нельзя менять систему.

### 2. Скопировать папку `kiosk` на плеер и запустить установку

PowerShell от имени администратора, в папке со скриптами:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -ServerUrl http://10.33.44.20:8080 -KioskUser signage
```

Параметры:

- `-ServerUrl`: адрес сервера, как `server.publicUrl` в конфиге сервера.
- `-KioskUser`: пользователь киоска. Если не указан, задача срабатывает при входе любого пользователя.
- `-ActiveHoursStart 6 -ActiveHoursEnd 23`: активные часы Windows Update. Сам Windows перезагружается только вне этого интервала, то есть ночью.

Скрипт копирует файлы в `C:\Signage`, сохраняет прежние настройки в `C:\Signage\install-backup.json` и пишет журнал в `C:\Signage\logs\`.

### 3. Включить автоматический вход (Sysinternals Autologon)

1. Скачайте Autologon с сайта Microsoft: <https://learn.microsoft.com/sysinternals/downloads/autologon>.
2. Запустите `Autologon64.exe` от администратора.
3. Укажите **Username** `signage`, **Domain** — имя компьютера, **Password** — пароль из шага 1. Нажмите **Enable**.

Autologon хранит пароль зашифрованным (LSA secret), а не открытым текстом в реестре.

### 4. Перезагрузить и зарегистрировать экран

1. Перезагрузите компьютер. Windows войдёт под `signage`, через несколько секунд откроется плеер.
2. На экране появится крупный 6-значный код.
3. В админке: **Экраны и группы → Добавить экран**, введите код, имя и группу.
4. Плеер запомнит токен, при следующих запусках код не нужен.

## Проверка

- [ ] После перезагрузки плеер открывается сам, без рамок и панелей Windows.
- [ ] Курсор не виден, фон чёрный.
- [ ] В админке экран «в сети», в колонке «Плеер» видно разрешение и «кэш N/N». Если там «кэш выкл», Service Worker не работает: проверьте, что `-ServerUrl` совпадает с адресом в браузере.
- [ ] Закройте браузер (`Alt+F4`): через 10–15 секунд он откроется снова.
- [ ] Отключите сетевой кабель: контент продолжает играть, в правом нижнем углу появляется красная точка. Подключите обратно: точка исчезает.
- [ ] Экран не гаснет через 10–30 минут.

## Обслуживание: выход из киоска

Watchdog перезапускает браузер, поэтому сначала его нужно остановить.

**Вариант 1, проще всего.** Создайте файл `C:\Signage\maintenance.flag`: через `Ctrl+Alt+Del` → «Диспетчер задач» → «Запустить новую задачу» → `cmd /c type nul > C:\Signage\maintenance.flag`, или по сети, или через RDP. Watchdog перестанет поднимать браузер, закройте его `Alt+F4`. Чтобы вернуть киоск, удалите файл.

**Вариант 2, остановить задачу** (PowerShell от администратора, например по RDP):

```powershell
Stop-ScheduledTask -TaskName 'Signage Kiosk'
```

Затем закройте браузер `Alt+F4`.

Чтобы снова запустить киоск, выйдите из системы и войдите заново или выполните `Start-ScheduledTask -TaskName 'Signage Kiosk'` под пользователем `signage`.

## Смена адреса сервера

Запустите `install.ps1` повторно с новым `-ServerUrl`. Исходные значения настроек Windows при этом не перезаписываются. Токен экрана хранится в профиле браузера на сервере старого адреса, поэтому на новом адресе экран попросит код заново.

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File C:\Signage\uninstall.ps1
```

Скрипт удаляет задачу, останавливает браузер киоска, возвращает реестр и параметры питания из `install-backup.json` и удаляет `C:\Signage`. С ключом `-KeepProfile` папка остаётся. Отключите автоматический вход: Autologon → **Disable**.

## Что именно меняет установка

- **Питание:** `monitor-timeout-ac 0`, `standby-timeout-ac 0`, `hibernate-timeout-ac 0`.
- **Политики Edge** (`HKLM\SOFTWARE\Policies\Microsoft\Edge`): без экрана первого запуска, вход в аккаунт и синхронизация выключены, автовоспроизведение разрешено, перевод и уведомления сайтов выключены, `OverrideSecurityRestrictionsOnInsecureOrigin = <ServerUrl>` (Service Worker по http).
- **Windows:** выключены центр уведомлений, рекомендации и «советы», окно отчёта об ошибках.
- **Windows Update:** активные часы и `NoAutoRebootWithLoggedOnUsers`.
- **Пользователь киоска** (применяет watchdog при каждом входе): выключены всплывающие уведомления, подсказки, «завершите настройку устройства» и заставка.

Строка запуска браузера:

```
msedge.exe --kiosk "<ServerUrl>/player/" --edge-kiosk-type=fullscreen
  --user-data-dir=C:\Signage\EdgeProfile --no-first-run --noerrdialogs
  --disable-session-crashed-bubble --disable-features=Translate
  --autoplay-policy=no-user-gesture-required
  --unsafely-treat-insecure-origin-as-secure=<ServerUrl>
  --disable-pinch --overscroll-history-navigation=0
```

## Неполадки

| Симптом | Что проверить |
|---|---|
| Браузер не запускается после входа | `C:\Signage\logs\watchdog.log`; задача **Signage Kiosk** в планировщике; нет ли файла `maintenance.flag` |
| Белый экран «Не удаётся открыть страницу» | Плеер не видит сервер. Плеер сам переподключится; если был кэш, он продолжит показ |
| Код регистрации появляется снова | Экран удалили в админке или очистили профиль `C:\Signage\EdgeProfile` |
| Видео не воспроизводится | Кодек: нужен H.264 (mp4) или VP8/VP9 (webm). Админка предупреждает при загрузке |
| Windows перезагрузился днём | Активные часы: `Параметры → Центр обновления Windows → Период активности` |
